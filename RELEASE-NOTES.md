# LearkPeN v0.0.10

Developed by learkcompany.

Windows companion with a native interface, English/Persian language selection, light/dark/system themes, and background USB processing. Includes fixes for menu disposal and native button border artifacts.

Windows assets: LearkPeN-Setup-v0.0.10.exe and LearkPeN-v0.0.10-Windows.zip.

iPad source: v0.0.9, compatible with the Windows v0.0.10 companion. Import into Swift Playgrounds using the README instructions. This release does not provide an App Store or signed iPad installation package.
